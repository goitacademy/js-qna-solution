# Q&A-сесія: асинхронність, дати та проміси

### 🟢 Задача 1. Відкладене збереження

Після натискання кнопки одразу показати процес збереження, тимчасово вимкнути
кнопку, а через дві секунди повідомити про успішне завершення та знову дозволити
натискання.

**Що тренуємо:** асинхронне виконання, `setTimeout()`, колбек-функцію та
оновлення інтерфейсу після затримки.

### 🟢 Задача 2. Відлік до події

Запустити п’ятисекундний відлік на основі часу завершення. Щосекунди
перераховувати залишок, а після досягнення нуля зупинити інтервал і повідомити
про початок події.

**Що тренуємо:** `Date.now()`, часові мітки, `setInterval()`, `clearInterval()`
і асинхронне оновлення DOM.

### 🟡 Задача 3. Перевірка залишку

Створити функцію, яка імітує асинхронну перевірку товару. Через одну секунду
проміс має виконатися, якщо товару достатньо, або відхилитися, якщо залишок
менший за потрібну кількість. Результат показати на сторінці.

**Що тренуємо:** створення `Promise`, `resolve`, `reject`, `then()` і `catch()`.

### 🔴 Задача 4. Кінні перегони

Показати трьох коней у списку ставок. Після вибору коня запустити для кожного
окремий проміс із випадковим часом фінішу. Перший завершений проміс визначає
переможця. Потрібно показати його ім’я, перевірити ставку, а після завершення
всіх промісів дозволити запустити новий заїзд.

**Що тренуємо:** створення колекції промісів, випадкову асинхронну затримку,
`Promise.race()`, `Promise.all()`, `map()`, роботу зі станом інтерфейсу та
поєднання попередніх тем.
