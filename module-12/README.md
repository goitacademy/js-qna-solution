# Пошук товарів з async/await і пагінацією

Готове рішення комплексної практики для модуля 12. Проєкт є продовженням пошуку
товарів із модуля 11 і використовує `async/await`, `try...catch`, пагінацію та
кнопку «Завантажити ще».

## Запуск

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
```
